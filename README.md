# BudgetWise Finance Dashboard

##Project Overview

BudgetWise Finance is a financial analysis and dashboard project developed using **Excel and Power BI**.

The project focuses on cleaning and transforming financial transaction data, creating meaningful business metrics, and building an interactive dashboard to understand **income, expenses, transactions, and financial trends**.

## Objectives

- Clean and prepare raw financial transaction data
- Transform data into a structured format for analysis
- Create meaningful financial KPIs
- Build an interactive Power BI dashboard
- Analyze income and expenses
- Improve understanding of financial transaction patterns

##  Tools & Technologies

- **Microsoft Excel**
- **Power BI**
- **Power Query**
- **DAX**
- **Data Cleaning & Transformation**
- **Data Modeling**
- **Pivot Tables**

##  Project Files

| File | Description |

##  Project Workflow

### 1. Data Collection
Raw financial transaction data was collected and stored in CSV format.

### 2. Data Cleaning
The raw data was cleaned and prepared using Excel.

The cleaning process included:

- Handling missing values
- Cleaning date fields
- Checking invalid values
- Standardizing categories
- Identifying potential outliers
- Validating transaction amounts

### 3. Data Transformation

The cleaned data was structured for further analysis and dashboard development.

### 4. Data Analysis

Pivot tables and calculations were used to analyze:

- Total Amount
- Total Transactions
- Total Income
- Total Expenses
- Payment Modes
- Transaction Categories

### 5. Dashboard

An interactive financial dashboard was created to provide a quick overview of important financial KPIs.

##  Key Dashboard KPIs

The dashboard includes:

- **Total Amount**
- **Total Transactions**
- **Total Income**
- **Total Expense**

Additional analysis includes transaction categories and payment modes.

## Key Results

The final dashboard provides an overview of the financial dataset and helps users understand:

- Overall transaction volume
- Total income generated
- Total expenses
- Distribution of financial transactions
- Payment method usage
- Category-wise financial activity
